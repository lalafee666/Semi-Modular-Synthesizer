# Semi-Modular-Synthesizer


This project was developed as part of the university modules
Projekt Audio I & II at Hochschule Mittweida.

The goal of the project was to develop and build a complete semi-modular synthesizer.

## Project Work
- Development and modification of electronic circuits
- Schematic and PCB design using KiCad
- PCB assembly and soldering
- Design and construction of the user interface
- Design and construction of the enclosure
